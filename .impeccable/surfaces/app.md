# App surface

Scope: `/app`, `public/index.html`, `public/app.js`, `public/field-utility.css`.
Mode: Operate. Build path: code-led, explicitly chosen by the user.

## Direction contract

**THESIS:** A field utility for copying a test code and reading reception evidence,
not a generic rounded gradient dashboard.

**OWN-WORLD:** Flat charcoal/off-white surfaces, small-radius controls, ordinary
system text, mono codes and counts, restrained blue and compact separated rows.

**STORY:** Copy, transmit using MeshCore, then read observed/target counts. Waiting
is unmeasured. Defaults and nearby selection have different relevance, not different
promises of radio coverage.

**FIRST VIEWPORT:** Compact configured brand/header, code and destination channel
left with adjacent Copy/New/Share controls; count and horizontal meter right.
Score is secondary. Explanatory selection guidance remains visible beneath the
result. Mobile stacks result below the code, not before it.

**FORM:** User-pinned practical field utility. No seed key was produced: the parent
reported context/concept launchers permission-denied, and execution/retries were
explicitly prohibited for this source-only subtask. No fabricated assignment.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction: a copied code becomes measured reception; neutral Pending
rows and markers resolve to real Seen/Not Seen states without decorative animation.
No new raster assets; the existing configured logo is retained untouched.
